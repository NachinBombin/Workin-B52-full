# Workin-B52-full

Garry's Mod B-52 Stratofortress support aircraft entity based on the original TB-2 addon.

## Features
- B-52 model: `models/stuffs/boeingb52g/boeing_b52g_stratofortress.mdl`
- Engine loop: `sound/b52/b52.wav`
- 5 contrails instead of 1
- Near-max altitude orbiting
- Same weapons as TB-2 for now
- Spawn system, menu, NPC support calls
